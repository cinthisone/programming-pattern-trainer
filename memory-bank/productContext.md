# Product Context

Users should learn: Basics → Pattern → Algorithm → Implementation → Syntax.

Basics (variables, control structures, loops, arrays, sets) are a separate track from named patterns (accumulator, two pointers, and so on). Same language-independent problem model for both.

The workspace is a developer tool (VS Code / GitHub / Linear / Vercel), not a toy or generic AI SaaS dashboard.

Guests browse published curriculum. Registered users run, submit, save, and track progress. Admins manage curriculum and AI drafts. AI never auto-publishes.

Progressive hints (conceptual → pattern → strategy → pseudocode → solution). Translation practice is a first-class loop: same problem, new language.

Official tests are stdin/stdout pairs stored with the problem. Learners do not type those numbers unless they use **Try** with their own stdin. **Run tests** grades visible cases; **Submit** includes hidden cases without showing hidden I/O.
